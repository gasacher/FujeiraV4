FUJEIRA — subir esta versión a Hostinger
El catálogo es el actual: Retro Series y cuadros. El pago es Mercado Pago.

1. En GitHub abrí el código de esta rama y descargá el ZIP:
   https://github.com/gasacher/FujeiraV4/archive/refs/heads/cursor/laravel-mp-checkout-d363.zip

2. En hPanel entrá a Archivos → Administrador de archivos → public_html.

3. Subí el ZIP y extraelo. Se crea una carpeta. Abrila y mové TODO lo que hay adentro a public_html, al lado de donde estaba index.html.

4. Borrá el index.html viejo de public_html. Si queda, Hostinger sigue mostrando el sitio anterior.

5. Copiá el archivo .env.example y renombrá la copia a .env. Completá solo esta línea con el Access Token nuevo:
   MP_ACCESS_TOKEN=el_token_nuevo

6. En SSH de Hostinger (puerto 65002), desde public_html:

   composer install --no-dev --optimize-autoloader
   php artisan key:generate
   touch database/database.sqlite
   php artisan migrate --force
   chmod -R ug+rwx storage bootstrap/cache

7. Abrí https://fujeiraretrostore.com/catalogo

No subas el .env a GitHub. El token viejo que estuvo en el PHP hay que dejarlo revocado en Mercado Pago.
